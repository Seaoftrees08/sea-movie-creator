# 自律エージェントプラグイン 将来拡張メモ（Agent Future Features）

- **ステータス**: Memo / Future Backlog
- **作成日**: 2026-11-18
- **関連設計書**: [`../012-agentic-plugin-architecture.md`](../012-agentic-plugin-architecture.md)

このメモは、[`012-agentic-plugin-architecture.md`](../012-agentic-plugin-architecture.md) の MVP スコープ（既存 `VisualProperties` / `SubtitleProperties` / `AudioProperties` で組める範囲）を実装したあと、段階的に追加したい演出・機能モジュール・エージェントプラグインのアイデアを蓄積する場所です。

※ ここに記録された機能モジュールやシェーダ・ツールは、[`012-agentic-plugin-architecture.md`](../012-agentic-plugin-architecture.md) で導入する **4 層契約（`HostCapabilitySnapshot` / `HostToolRegistry` / `EditCommand` スキーマ / `ai_hints`）** に沿って本体へ追加することで、既存のエージェントプラグインからも自動的に認識・利用できるようになります。

---

## 1. 映像演出・WGSL シェーダ拡張候補（`EditCommand` / `VisualProperties` 拡張）

1. **高品質ガウスぼかし（Gaussian Blur）エフェクト**
   - 用途：スマホ縦長写真（9:16）を 16:9 キャンバスへ配置する際、MVP では「背面へ暗転・拡大コピー」で額縁表現を行うが、専用ぼかしパラメータを追加することで結婚式・Vlog で定番の「ふんわりぼかし背景」を美しく再現できる。
2. **装飾フレーム・ビネット・フィルムグレイン・ライトリークオーバーレイ**
   - 用途：レトロ感・フィルム風・ウェディング向けの柔らかい周辺減光や温かみのある質感調整を `EditCommand` パラメータまたはプロシージャルオーバーレイクリップとして選択可能にする。
3. **高度なトランジション（ワイプ・スライド・ホワイトアウト・ズームトランジション）**
   - 用途：MVP のクロスフェードに加えて、章の切り替わり（例：「新郎生い立ち」→「お二人の出会い」）でメリハリをつけるトランジションプリセットを提供する。
4. **3D/立体テキスト演出・縦書き字幕・背景帯（座布団）付きテロップ**
   - 用途：結婚式プロフィールムービーのタイトルや年代見出しをよりリッチに見せるための字幕背景ボックスや縦書きオプション。

---

## 2. 音楽・テンポ解析・音声連動機能候補

1. **BGM ビート・サビ（盛り上がり区間）検出ツール（`analyze_audio_beats`）**
   - 用途：音声波形エネルギーやテンポ（BPM）を純粋 Rust で解析し、曲の盛り上がりに合わせて章の切り替えや写真トランジションのタイミングを自動スナップさせる。
2. **Phase P1（音声作成 TTS）との連携ツール化**
   - 用途：ナレーション付きプロフィールムービーや解説動画を作る際、エージェントが台本生成→`HostToolRegistry` 経由で `yukkuri_batch_tts` を呼び出し、ナレーション音声の尺に合わせて写真表示時間を自動調整する。
3. **BGM 自動ダッキング（音声がある区間だけ BGM を自動で下げる）**
   - 用途：動画クリップやナレーション音声が重なる区間で、BGM の `gain_db` キーフレームを自動調整するツール。

---

## 3. エージェント拡張・UX 向上候補

1. **プレビュー視覚検査ツール（`render_preview_frame_vision`）**
   - 用途：生成したタイムラインの代表フレームを `WgpuCompositor` / ソフト合成器でレンダリングし、Vision モデルに「文字が顔に被っていないか」「余白が不自然でないか」を自己レビューさせる視覚フィードバックループ。
2. **顔位置・主要被写体検出に基づく自動トリミング/ズーム中心（`anchor_x`, `anchor_y`）調整**
   - 用途：Ken Burns ズーム時に人物の顔が画面外へ切れないよう、注目座標に合わせて移動・拡大の中心を自動補正する。
3. **ジャンル別エージェントプラグイン・テンプレートの拡充**
   - 例：旅行 Vlog 構成エージェント、商品紹介ショート動画（9:16 縦型）エージェント、ゲームハイライトまとめエージェント等。
4. **チャプター分割・一括スタイル変更のプリセットカタログ**
   - 例：「クラシック（明朝・セピア寄り）」「ナチュラル（柔らかフェード・白文字）」「ポップ（明るめ・軽快テンポ）」など、対話ステップで提示しやすいスタイルプリセットの拡充。
