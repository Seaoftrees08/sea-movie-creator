## 1. 概要・目的

現行の [`src/ui/timeline_panel.rs`](../../src/ui/timeline_panel.rs) は以下の点で AviUtl（拡張編集）および動画編集ソフトとして必須の操作性を満たしていない。

1. **上部ルーラーに時間・フレーム目盛りがない**: 空白帯と 2px 縦線のみで、現在時刻や尺の把握ができない。
2. **ルーラークリック座標のバグとドラッグスクラブ未対応**: [`timeline_panel.rs#L153`](../../src/ui/timeline_panel.rs#L153) で `evt.position.x - TRACK_HEADER_WIDTH` を用いており、`timeline_scroll_x_frames` およびパネル原点オフセットが未加算のため横スクロール時にシーク位置がずれる。また `on_mouse_move` による連続シーク（スクラブ）ができない。
3. **タイムライン長の変更・ズーム操作が貧弱**: 左上の青いズームバーや `Ctrl+ホイール`（カーソル基準ズーム）、プロジェクト最終フレーム位置（灰色縦線）の伸縮・指定手段がない。
4. **AviUtl ライクな直接操作・高密度表示の欠如**: 行高 `44px` 固定、左/右クリックによるコンテキストメニュー、中間点 `|` の区間クリック/ドラッグ、複数選択、マーキー囲み、`Ctrl+ドラッグ` 複製、音声波形描画が未実装。

本仕様では、AviUtl 拡張編集とほぼ同等のタイムライン操作感・視認性を、GPUI（`gpui-kit = "0.9.1"`）および既存の統一コマンド [`EditCommand`](../../src/timeline/command.rs) 上で実現するための詳細仕様を定義する。

## 2. スコープ

### 対象（In Scope）
- タイムライン上部ヘッダ（`[HH:MM:SS.ff] [current/total]`）および表示単位切替。
- ルーラー動的目盛り、左クリック＆ドラッグによるプレイヘッドシーク、選択範囲（`[` `]`）表示・ドラッグ。
- **「タイムラインの長さ変更」2 軸設計**（軸 A：表示ズーム＋スクロールバー、軸 B：最終フレーム境界線ドラッグ・自動追従・数値指定）。
- 高密度レイヤーヘッダ（`22px` / `30px` / `44px`）、表示/ミュート/ロック切替、仮想スクロール、右クリックメニュー。
- オブジェクト（クリップ）描画、音声波形オーバーレイ、中間点 `|` 描画・区間クリック・ドラッグ移動、複数選択、`Ctrl+ドラッグ` 複製、スナップ。
- 空白欄 / オブジェクト / ルーラー / レイヤー別の右クリックコンテキストメニュー（`ContextMenuExt`）。

### 対象外（Out of Scope）
- オブジェクト別の設定パラメータ UI（[`03-inspector-dialog-spec.md`](03-inspector-dialog-spec.md) で定義）。
- プレビューキャンバス上の直接ドラッグ＆ショートカット表全体（[`04-preview-and-shortcuts-spec.md`](04-preview-and-shortcuts-spec.md) で定義）。

## 3. 要件・制約

- **機能要件**:
  - 左クリックまたは左ドラッグでルーラー上の任意の時刻・フレームへ `0` 遅延感覚でシークでき、横スクロール状態でもクリック位置と再生ヘッド位置が 1px の狂いなく一致すること。
  - AviUtl ユーザが直感で使う「左上ズームバー」「`Ctrl+ホイール`」「最終フレーム変更」「空欄右クリック追加」「中間点クリック＆`P`追加」「`Ctrl+ドラッグ`複製」が動作すること。
  - すべてのタイムライン改変が [`EditCommand`](../../src/timeline/command.rs) 経由で実行され、Undo / Redo で完全復元可能であること。
- **非機能要件**:
  - 100 レイヤー・1,000 クリップ環境でも可視フレーム範囲＆可視行カリングにより 60fps（16ms 以内）で再描画できること。
  - ドラッグ操作中に数百個の `EditCommand` を履歴へ積まず、ドラッグ完了時（マウスアップ）に **1 コマンド（または `EditCommand::Batch` 1 個）** として確定すること。

### 4.1 タイムライン全体レイアウト構造

+---------------+-----------------------------------------------------------------------------------+
| 左上コーナー  | ルーラー帯 (32px):                                                                |
| [■ 青ズーム ■] |  00:00:00.00   00:00:02.00   00:00:04.00   00:00:06.00 ...  | 最終フレーム | 暗色  |

+---------------+-----------------------------------------------------------+-------------+-------+

### 4.2 上部タイムコードルーラー＆シーク仕様

#### A. ヘッダ時刻表示と単位切替
- 中央タイトル：`拡張編集 [00:00:02.86] [173/1852]`
  - 左括弧内は `TimeDisplayUnit` に応じて表示：
    - `Timecode` モード（既定）：`HH:MM:SS.cc`（例：`00:00:02.86`、秒未満はフレーム比率またはフレーム表記 `HH:MM:SS:FF` を設定可能、AviUtl 既定風は `.xx` 1/100秒換算または `:FF`）。
    - `Frames` モード：現在フレームと選択位置フレームのみ強調。
  - 右括弧内：`[現在フレーム / プロジェクト総フレーム]`（`[173/1852]`）。
  - ヘッダ時刻バッジのクリックで `Timecode` ⇔ `Frames` を即座にトグル可能とする。

#### B. 動的目盛りアルゴリズム（ルーラーティック）
`px_per_frame` と `fps` に応じ、文字が重ならない（最小ラベル間隔 `84px` 以上）最大の視認ステップを選択する。

| `px_per_sec = px_per_frame * fps` | 大目盛り（数値ラベル付き・高さ 12px） | 中目盛り（高さ 7px） | 小目盛り（高さ 4px） |
| --- | --- | --- | --- |
| `< 12 px/s` | `30s` 間隔 | `10s` | `5s` |
| `12 .. 30 px/s` | `10s` 間隔 | `5s` | `1s` |
| `30 .. 70 px/s` | `5s` 間隔 | `1s` | `0.5s`（`fps/2`） |
| `70 .. 180 px/s` | `1s` 間隔 | `0.5s` | `0.1s`（または `5f`） |
| `>= 180 px/s` | `0.5s` または `10f` 間隔 | `5f` | `1f` 境界線（`px_per_frame >= 6.0` で全フレーム線描画） |

- `TimeDisplayUnit::Frames` 時は、秒ステップの代わりに `1f / 5f / 10f / 30f / 60f / 120f / 300f / 600f` ステップから `px_per_frame * step >= 72px` となる最小候補を採用する。
- 可視開始フレーム `visible_start_f = timeline_scroll_x_frames`、可視終了フレーム `visible_end_f = visible_start_f + ceil(viewport_w / px_per_frame)` に対して、該当範囲の目盛りだけをループ生成する。

#### C. 正確な座標変換と再生ヘッドシーク（バグ修正）
現行 [`timeline_panel.rs#L153`](../../src/ui/timeline_panel.rs#L153) では `evt.position.x` から `TRACK_HEADER_WIDTH` を引くのみで `timeline_scroll_x_frames` やパネル自身のウィンドウ左端 `timeline_panel_bounds.origin.x` を考慮していない。以下の変換を純粋関数として定義し全マウス処理で共用する。

```text
track_canvas_origin_x = timeline_panel_origin_x + TRACK_HEADER_WIDTH
local_canvas_x        = f32::from(evt.position.x) - track_canvas_origin_x
raw_frame_f64         = timeline_scroll_x_frames as f64 + (local_canvas_x as f64 / px_per_frame as f64)
target_frame          = raw_frame_f64.round().max(0.0) as u64
clamped_frame         = target_frame.min(seek_upper_bound_frames)
```

- **ルーラー左クリック（`MouseDown`）**:
  1. 再生中（`PlaybackState::Playing`）であれば一時停止（`Pause`）。
  2. `Shift` キー非押下時：`seek_to_frame(clamped_frame)` を即時実行し、`TimelineDragState::ScrubPlayhead` を開始する。
  3. ルーラー外へドラッグが続いても（ウィンドウの `on_mouse_move` キャプチャ経由で）連続スクラブを継続し、左/右端付近にカーソルが出た場合は自動オートスクロールを行う。
  4. `MouseUp` で `ScrubPlayhead` を終了し、最終フレームを正確評価する。
- **再生ヘッド表示**:
  - ルーラー下端（y = 20..32px）に下向き逆三角形（幅 `11px`）を描画し、そのまま全レイヤーを貫通して最下段まで `1.5px` 縦線（`#38BDF8`、再生中は高輝度）を描画する。
- **ルーラー上 `Shift + 左ドラッグ`（選択範囲指定）**:
  - ドラッグ開始フレーム `anchor_f` と現在フレーム `cur_f` から `FrameRange { start: min(anchor_f, cur_f), end: max(anchor_f, cur_f).max(min + 1) }` を構成し、`MouseUp` 時に `EditCommand::SetSelectionRange` を発行する。

### 4.3 「タイムラインの長さ変更」2 軸設計

ユーザーから明確に要望された「AviUtl と同じようにタイムラインの長さを変えたりもできる」要件に対し、混同されやすい **2 つの「長さ」** を明快に分離し、双方を AviUtl そのままの操作感で実装する。

#### 軸 A：タイムライン表示スケール（ズーム＆表示領域移動）
1. **左上「青いズームバー」（`136px × 32px` コーナー内）**:
   - ルーラー左横（`Layer` ヘッダの上）に横幅 `120px` の青いトラックバー（背景 `#1F2937`、塗りつぶし `#2563EB`、左右端に拡大/縮小矢印または数値ヒント）を配置する。
   - **操作則**: 0.0（最小ズーム `0.2 px/f`・全体俯瞰）〜 1.0（最大ズーム `32.0 px/f`・フレーム単位編集）を対数スケール（`px = 0.2 * (32.0 / 0.2)^ratio`）で連続変更する。
   - **中心固定則**: ズームバー操作時は「現在再生ヘッドが画面内にある場合は再生ヘッド画面 X 座標を維持し、画面外にある場合はトラック領域中央のフレームを維持」するよう `timeline_scroll_x_frames` を同時再計算する。
2. **`Ctrl + マウスホイール`**:
   - カーソル下のフレーム `cursor_frame` を固定点とし、ホイール1ノッチあたり `× 1.25` / `÷ 1.25` 倍（`0.2 ..= 32.0` クランプ）へ拡大縮小する。
3. **ホイール / 横スクロールバー**:
   - 通常の縦ホイール：垂直スクロール（レイヤー上下移動）。
   - `Shift + ホイール` または横ドラッグホイール（トラックパッド）：水平スクロール（フレーム移動）。
   - 下部横スクロールバーの全体長：`total_scrollable_frames = document.ruler_display_span_frames() + padding_frames`（画面右端にも少し余白を残し、末尾編集しやすいようにする）。

#### 軸 B：プロジェクトの最終フレーム（タイムライン長・尺の変更）
1. **最終フレーム境界線（灰色縦線 `#64748B`）の直接ドラッグ**:
   - `x = frame_to_canvas_x(document.total_duration_frames())` の位置に、ルーラーから全レイヤーを貫通する **2px 灰色縦線**（上端に掴みやすい小さなハンドル `]` アイコン付き）を描画する。
   - この線から右方向（`x > final_line_x`）は、タイムライン背景を暗色（`#0F1115`）でマスクし、「再生・書き出し範囲外」であることを AviUtl と一目で同じように示す。
   - **直接ドラッグ仕様**:
     - マウスホバーでカーソルを `ew-resize`（左右矢印）へ変化させる。
     - 左ドラッグ開始で `TimelineDragState::ResizeTimelineEnd { initial_end_frame, preview_end_frame }` へ遷移（スナップ有効時は隣接クリップ終端・現在フレームにスナップ）。
     - ドラッグ中はツールチップで新しい長さ（例：`1852f (00:00:30.86)`）を表示。
     - ドロップ時に `EditCommand::SetTimelineLength { mode: TimelineLengthMode::Manual { end_frame } }` を発行（Undo 1 回で戻る）。
2. **右クリックメニュー／メニューバーからの長さ設定**:
   - `最後のオブジェクト位置を最終フレーム`（AviUtl と同名称）：`clips_end_frame()` へ即座に設定（モードは手動固定またはユーザー選択で自動追従 `AutoToLastClip` へ切替）。
   - `タイムライン長を設定...`：ミニモーダルを開き、`AutoToLastClip` ラジオボタン / `Manual`（フレーム数 `NumberInput` または `HH:MM:SS.ff` 入力）を指定できる。
3. **ヘッダ左上ステータスバッジ**:
   - `[尺: 自動 1852f]` または `[尺: 手動 2400f]` バッジを表示し、クリックで長さ変更メニューを即座に開ける。

### 4.4 レイヤー構造と高密度表示仕様

#### A. レイヤーサイズ密度（`TimelineRowDensity`）
| モード | 行高 (`px`) | レイヤーヘッダ構成 | オブジェクト表示内容 |
| --- | --- | --- | --- |
| **`Compact`（既定・AviUtl 準拠）** | `22.0` | `Layer N`（任意名あり時は併記）+ 小アイコン `[👁][🔊][🔒]`（左からコンパクト配置） | クリップ名 1 行 + 中間点縦線 `\|` + 音声簡易中心波形 |
| **`Medium`** | `30.0` | レイヤー名 1 行 + 見やすいアイコンボタン | クリップ名 + 音声上下対称波形 |
| **`Large`** | `44.0` | 2 段レイアウト（名称 + 操作アイコン＋クリップ数バッジ） | クリップ名 + 補助時間文字 + 高精細波形 |

- **重ね順の統一**: 配列 [`ProjectDocument::layers`](../../src/timeline/document.rs) のインデックス `0` を最上段に `Layer 1` として表示し、インデックスが増えるにつれて下段 `Layer 2, Layer 3...` として表示する。合成順序は「インデックス大（下段ほど前面）」であり、**AviUtl と 100% 一致**する。

#### B. レイヤーヘッダのクリック／右クリック操作
- `[👁]`（`visible` トグル）：クリックで [`EditCommand::SetLayerFlags`](../../src/timeline/command.rs)（`visible: Some(!layer.visible)`）を発行。非表示レイヤーはタイムライン行全体も半透明暗色化（`opacity: 0.45`）。
- `[🔊]`（`muted` トグル）：音声再生のみミュート（視覚は維持）。
- `[🔒]`（`locked` トグル）：ロック中レイヤー上ではクリップの移動・リサイズ・削除・中間点操作・追加をブロックし、薄い斜線ハッチまたは鍵アイコンで明示。
- **ダブルクリック**：レイヤー名のインライン編集（`Input` 一時表示、`Enter` 確定 / `Esc` キャンセル）。
- **右クリックコンテキストメニュー**:
  - `レイヤー名を編集`
  - `上に新規レイヤーを挿入` / `下に新規レイヤーを挿入`
  - `このレイヤーを非表示にする` / `他レイヤーをすべて非表示` / `全レイヤー表示`
  - `レイヤーロック切替`
  - `トラック高さ` サブメニュー → `小 (22px)` / `中 (30px)` / `大 (44px)`
  - `このレイヤーを削除`（空レイヤー時は即時、クリップあり時は確認）

### 4.5 クリップ（オブジェクト）描画・選択・ダイレクト編集仕様

#### A. クリップ見た目と中間点 `|` 表示
```text
+-------------------------------------------------------------------+
|◆ 動画タイトル.mp4             |                   |             ◆|  <-- クリップ上部/境界
|  (区間0: 0..60f)             |   (区間1: 60..140f)|  (区間2)    |      青背景＋黄色選択枠
+-------------------------------+-------------------+---------------+
                                ^                   ^
                            中間点 (| + 上端◆)   中間点 (| + 上端◆)
```
- **中間点描画**: `clip_midpoint_effect_frames(&clip.id)` のうち有効範囲（`eff_start < m < eff_end`）の各フレーム位置に、`2px` 白色縦線 + 上端 `6px` 菱形ハンドル（選択中/ホバー時 `#FACC15` 強調）を描画する。
- **区間ハイライト**: `selected_clip_id` に一致するクリップでは、外枠を `#FACC15`（2px）で囲み、さらに `selected_segment_index` 以外の区間をわずかに暗め（黒 `20%` オーバーレイ）または現在区間の背景上端に `2px` 青ハイライトラインを引くことで「今どの区間を設定ダイアログで編集中か」を一目で分かるようにする。
- **クリップ左クリック（区間自動連動）**:
  - クリック位置 X から `clicked_eff_frame` を算出し、そのクリップ内の中間点列 `[eff_start, m_1, ..., m_k, eff_end]` の何番目の区間に落ちたかを特定する。
  - 修飾キーなしクリック：`select_single_clip(Some(clip_id), segment_index)`。これにより **中間点の左側をクリックすれば前半設定、右側をクリックすれば後半設定** が設定ダイアログに即座に表示される（AviUtl と同一挙動）。
  - `Ctrl + クリック`：`toggle_clip_selection(&clip_id)`（複数選択の追加・除外）。
  - **中間点マーカー自体の左クリック＆ドラッグ**：マーカー周囲 `±5px` 内であれば `TimelineDragState::MoveMidpoint { clip_id, old_eff_frame, current_eff_frame }` へ入り、ドラッグで中間点位置を前後へ移動する。
  - **中間点マーカーダブルクリック**：その中間点時刻へ再生ヘッドを即座にジャンプ。

#### B. 音声波形オーバーレイ描画
- 対象：`ClipKind::Audio`（赤 `#B91C1C` 背景）、および将来動画クリップの音声帯表示ON時。
- データ取得：[`AudioMixer::waveform_peaks(&asset_id, samples_per_peak)`](../../src/audio/mixer.rs) を利用してピークキャッシュ（`min` / `max` 列）を取得する。UI 描画パス内ではデコードを行わず、`None`（バックグラウンド生成中）の場合は「波形読込中...」またはフラットラインのみ描く。
- クリップ内ピクセル幅 `w_px` に対し、`1..2px` ごとに該当時間区間 `[source_in + dt_0, source_in + dt_1]` の最大ピーク振幅を取り、`#4ADE80`（薄半透明の黄緑〜白）で波形を描画する。
- トリム（`source_in` 変更）時は `source_in` オフセットに追従して波形も正しく横ずれし、波形上の無音/発話点を見ながら正確なカット編集が可能になる。

#### C. ドラッグ移動・トリム・`Ctrl+ドラッグ`複製・マーキー囲み選択
| マウス操作 | ヒット対象 | 状態 (`TimelineDragState`) | 確定時に発行する `EditCommand` |
| --- | --- | --- | --- |
| 左ドラッグ | クリップ中央（非端・非中間点） | `MoveClips { initial, delta_frames, target_layer_delta }` | 単一：`MoveClip`、複数：`Batch([MoveClip...])`（衝突回避順生成） |
| **`Ctrl + 左ドラッグ`** | 選択クリップ中央 | `DuplicateAndMoveClips { clones_preview, delta_frames, target_layer_delta }` | `build_duplicate_selection_command` 相当＋移動先の `Batch`（元クリップは残置、ゴースト表示） |
| 左ドラッグ | クリップ左端 `±6px` | `TrimLeft { clip_id, new_start }` | `EditCommand::TrimLeft`（最小 `1f` 制限） |
| 左ドラッグ | クリップ右端 `±6px` | `TrimRight { clip_id, new_end }` | `EditCommand::TrimRight`（最小 `1f` 制限） |
| 左ドラッグ | タイムライン空白部 | `MarqueeSelect { start_pos, current_pos, additive }` | （`EditCommand` なし・`select_clips_in_rect()` 更新） |
| 中クリックドラッグ / `Space+ドラッグ` | タイムライン全体 | `PanTimeline { start_scroll_x, start_scroll_y }` | （ビューポート移動のみ） |

- **スナップエンジン統合（[`src/timeline/snap.rs`](../../src/timeline/snap.rs)）**:
  - ドラッグ移動・トリム・中間点移動・最終フレームドラッグ中は `snap_config`（有効閾値例 `8px` 相当のフレーム数）を用いて以下に自動スナップし、縦シアン/イエローのガイド線（`snap_guide_frame`）を描画する：
    1. 現在再生フレーム（プレイヘッド）
    2. 同一・他レイヤーのクリップ開始端および終了端
    3. 他レイヤーの中間点
    4. 選択範囲の `[` / `]` 境界およびプロジェクト最終フレーム
  - `Shift` キーを押しながらドラッグしている間はスナップを一時無効化し、`1f` 単位で自由に配置可能（Alt でも切替可）。

## 6. エラーハンドリング・エッジケース

- **パネル幅極小時（例：横幅 400px 以下）**: `TRACK_HEADER_WIDTH` は `136px` を維持しつつトラック領域が `0px` 以下にならないようクランプし、ゼロ除算や負幅によるスクロール崩壊を防ぐ。
- **ドラッグ中のウィンドウ外マウスリリース**: タイムライン全体だけでなくウィンドウルート（[`window.rs`](../../src/ui/window.rs)）側でも `on_mouse_up` / `on_mouse_move` をフックし、ルーラーやパネル外へマウスが出て指を離してもドラッグ状態が張り付かないように保証する。
- **重なり衝突時の挙動**: 複数クリップドラッグ先がロック中レイヤー、または非選択クリップと重複する場合、ドロップ前にリアルタイム衝突検査結果を赤色半透明ゴーストで警告表示し、ドロップ時にも検証失敗した場合は元位置へ安全にロールバック＋ステータスメッセージ通知する。
- **最小クリップ長 `1f` 制約**: `TrimLeft` / `TrimRight` ドラッグで幅が `0f` 以下にならないよう `1f` でクランプする。中間点移動も `[eff_start + 1, eff_end - 1]` かつ隣接中間点と `1f` 以上離す。
- **長尺タイムラインでの数値オーバーフロー**: `frame * px_per_frame` は計算時に `f64` を経由してから描画ローカル座標へ変換し、スクロール先が巨大（例：10 時間 = 2,160,000f）でも丸めジッタや `i32` 飽和を起こさない。

## 7. テスト計画・受け入れ基準

### 単体テスト（`src/ui/timeline_panel.rs` 末尾 `#[cfg(test)] mod tests`）
1. `frame_from_window_x` テスト：`scroll_x_frames > 0` かつ `track_canvas_origin_x > 0` の条件下でクリックと逆算 `canvas_x_from_frame` が `±0` フレーム誤差で一致すること。
