# sea-movie-creator ユーザーガイド

`sea-movie-creator` は、タイムライン（拡張編集風）・プレビュー直接操作・設定ダイアログ風クリップインスペクタ・AI アシスタントをシングルウィンドウに統合した動画編集エディタです。

---

## 1. 起動と画面構成

```bash
cargo run
```

ウィンドウは次の領域で構成されています。

1. **上部メニューバー**: `ファイル`・`編集`・`タイムライン`・`設定`・`表示`・`再生`・`書き出し` の 7 メニューと、現在時刻・プロジェクト状態のサマリーを表示します。
2. **中央上部 プレビューエリア**:
   - ヘッダーバー（解像度表示、ズーム倍率 `Fit` などの切替、ガイド `枠`・グリッド `#`・波形表示トグル）
   - キャンバス直接操作ビュー（ドラッグ移動、拡縮ハンドル、回転ハンドル、中心アンカー `⊕`）
   - 主音声波形ストリップ（クリック/ドラッグでシーク）
   - トランスポートバー（`1f` コマ送り、再生/一時停止/停止、先頭/末尾ジャンプ、再生位置で分割）
3. **下部 タイムライン（拡張編集）**: 左上のズームバーと機能ヘッダー、動的ルーラー、高密度レイヤー行（仮想スクロール対応）、水平スクロールバーを備えます。
4. **右側 パネル（4 タブ構成）**: スプリッタで横幅を調整可能（最小幅 `240px`）。
   - `クリップ`: 選択中クリップの設定ダイアログ（中間点バー・`TrackBarRow`・折りたたみセクション群）
   - `AIチャット`: 自然言語によるタイムライン/クリップ編集指示
   - `レイヤー`: レイヤー一覧の可視/ミュート/ロック・並び替え管理
   - `プロジェクト`: 解像度・FPS・タイムライン長設定（自動 / 手動）

## 2. ファイル・素材読み込みと欠損メディア管理

- **新規・保存・開く**: メニュー `ファイル` または `Ctrl+N` / `Ctrl+O` / `Ctrl+S` / `Ctrl+Shift+S` でプロジェクトファイル（`.smc.json` 等）を読み書きできます。
- **素材の追加**:
  - メニュー `ファイル` → `素材を追加...`（`Ctrl+I`）
  - エクスプローラー等からタイムラインへ動画・画像・音声ファイルを直接ドラッグ＆ドロップ（ドロップ位置のフレーム・レイヤーへ配置）
  - 空きトラック右クリック → `新規追加` → `動画・画像・音声ファイル...` / `テキスト・字幕 (...)`
- **欠損メディアの再リンク**: 素材ファイルが見つからない場合はプレビュー上部にオフライン通知バナーが表示され、再リンク導線から参照先ファイルを差し替えられます。

## 3. 「拡張編集」タイムラインの使い方

### 3.1 ヘッダーバー・ズーム・時間表示

| コントロール | 機能 |
| --- | --- |
| 左上ズームバー（`−` / スライダ / `+`） | タイムライン横縮尺を調整（`Ctrl+ホイール`・`Ctrl+=` / `Ctrl+-` でもカーソル位置基準で拡縮可能） |
| `TC` / `Frame` ピル | ルーラーやヘッダの時刻表示をタイムコードとフレーム番号で切替 |
| `尺: 自動 (...)` / `尺: 手動 (...)` | タイムライン長変更モーダルを開き、`自動（最後のクリップ末尾に追従）` と `手動（終了フレーム指定）` を切替 |
| `追従` トグル | 再生ヘッド移動時に、現在フレームと重なるクリップへ選択を自動追従させるか切替 |
| `スナップ` トグル | クリップ端・再生ヘッド・中間点への吸着を切替（ドラッグ中に `Shift` を押すと一時解除） |
| `高さ: 小` / `中` / `大` | トラック行高さを 22px / 30px / 44px の 3 段階で切替 |
| `+ レイヤー` | 末尾に新しいレイヤーを追加 |

- **タイムライン長の変更**: 上記ヘッダの `尺:` ボタン、`Ctrl+L`、右パネル `プロジェクト` タブ、またはタイムライン右端の最終フレーム境界縦線を直接ドラッグして長さを変更できます（`手動` 時は範囲外が暗色マスクされます）。

### 3.2 ルーラー・選択範囲・シーク

- ルーラー上をクリック／ドラッグすると即座に再生ヘッドがそのフレームへシークします。
- 選択範囲 `[start, end)` は `[`（開始点設定）・`]`（終了点設定）、ルーラー上の `Shift+ドラッグ`、または右クリックメニューで設定でき、青色オーバーレイで表示されます。`Ctrl+Shift+A` で選択範囲を解除できます。

### 3.3 クリップ・中間点・トラックの操作

- **移動とトリミング**: クリップ中央をドラッグで別時間・別レイヤーへ移動、左右端ドラッグで開始/終了位置をトリミングします。
- **複数選択と複製**:
  - 空白領域からドラッグするとマーキー矩形で複数クリップを囲み選択できます。
  - `Ctrl+クリック` で個別に追加/解除、選択クリップを `Ctrl+ドラッグ` すると複製して移動します。
- **分割と字幕挿入**: 再生位置で `S` キー（分割）、`T` キーで現在トラック・再生位置へ字幕クリップを挿入できます。
- **中間点（`◆`）**:
  - `M` で再生位置へ中間点を追加、`Shift+M` で再生位置付近の中間点を削除します。
  - タイムライン上の黄色いひし形 `◆` をドラッグして中間点の時刻を移動でき、区間をクリックすると右パネルの編集対象区間も切り替わります。
- **音声波形表示**: 動画（音声付き）や音声クリップでは、`source_in` と `playback_rate` に同期した波形バーがクリップ内に描画されます。
- **トラックヘッダ操作**: レイヤーヘッダはダブルクリックまたは右クリックで名前変更でき、可視（目）・ミュート・ロックボタンや上下トラック挿入・削除を行えます。

### 3.4 タイムラインの右クリックメニュー

クリックした対象ごとに専用コンテキストメニューが開きます（ロック済みレイヤーでは変更系項目が自動的に無効化されます）。

- **空きトラック**: `テキスト・字幕` / `動画・画像・音声ファイル...` の追加、`ここに貼り付け`、選択開始/終了点設定、`最後のオブジェクト位置を終了点にする`、`タイムライン長を設定...`、`スナップを有効` / `シークで選択を追従` / `フレーム番号表示` トグル
- **クリップ**: `このクリック位置で分割` / `再生位置で分割 (S)`、`クリック位置へ中間点を追加` / `再生位置へ中間点を追加`、`切り取り` / `コピー` / `複製` / `削除`、`先頭を再生位置へ移動` / `末尾を再生位置へ揃える`、`インスペクタを開く`
- **中間点（`◆`）**: `中間点を削除`、`この中間点へシーク`、`所属クリップを選択`
- **ルーラー**: `このフレームへシーク`、`時間表示: タイムコード / フレーム番号`、選択範囲設定/クリア、`最後のクリップ末尾を終了点にする`、`タイムライン長を設定...`
- **レイヤーヘッダ**: `レイヤー名を変更...`、`上にトラックを挿入` / `下にトラックを挿入`、`表示 / 非表示`、`ミュート`、`トラックをロック`、`このトラックを削除`

## 4. 「クリップ」設定ダイアログ（右パネル）

単一クリップ選択時は、AviUtl の設定ダイアログに近いパラメータ編集画面が表示されます。

- **レスポンシブ幅**: 右パネル幅が `240px〜379px` の場合はラベル・数値・スライダを 2 段表示、幅 `380px` 以上では 1 行横並びへ自動切替されます。
- **中間点ナビゲーションバー**: 上部に `区間 i/N · 中間点 M · @Xf` と `◀ [区間バー] ▶ [+][-]` が並び、左右ボタンや区間クリックで編集対象区間を切り替え、`+`/`-` で中間点の追加・削除ができます。
- **`TrackBarRow` の操作**:
  - 各項目（`X`、`Y`、`拡大率`、`透明度`、`回転`、色調補正パラメータ、音量・パン等）について、左右のトラックバースライダ、`Shift+ドラッグ` による `1/10` 微調整、`<`/`>` 微調ボタン、数値入力欄で始点値・終点値を編集できます。
  - 中央の移動方法ボタンから `移動なし` / `直線移動` / `加減速移動` / `加速移動` / `減速移動` / `ベジェ曲線` / `キーフレーム` / `数式 f(t)` を切り替えられます（右欄の直接編集で自動的に直線アニメーションへ昇格します）。
  - `拡大率` の縦横比ロックボタンを切り替えると X/Y 拡大率を連動して変更できます。
  - 各行を右クリックすると、`既定値に戻す`・`全区間の値を同じにする`・`数式 f(t) で編集...`・`他スロットへカーブをコピー` メニューが利用できます。
- **折りたたみセクション**:
  - `標準描画`: X / Y / 拡大率 / 透明度 / 回転 / 中心アンカー（`AnchorX` / `AnchorY`） / ブレンドモード
  - `色調補正`: 明度 / コントラスト / 彩度 / 色相 / ガンマ
  - `字幕設定`: テキスト本文（複数行）、フォント、サイズ、配置、文字色・縁取り色・縁取り幅
  - `音声再生`: ミュート / 音量 / パン / 再生速度変更時のピッチ維持 / VST3・CLAP オーディオエフェクト
  - `数式 f(t) / カーブ詳細`: 数式式入力・カーブグラフ確認
- **複数選択時**: 選択数に応じた一括複製・一括削除や、`ΔX` / `ΔY` 相対オフセットの一括適用を行えます。

> **注**: 内部データでは不透明度 (`0.0〜1.0`) として保持されますが、UI 上は AviUtl 準拠の **透明度（`0.0〜100.0`、`0` が不透明、`100` が完全透明）** として表示・入力できます。

## 5. プレビュー直接操作と主音声波形

- **ヘッダー操作**: ズーム切替（`Fit` や固定倍率）と、表示切替ボタン（`枠` ガイド表示、`#` グリッド表示、主音声波形表示）を備えます。
- **キャンバス直接操作**:
  - **移動**: プレビュー上のクリップを左ドラッグで `X` / `Y` を移動（`Shift+ドラッグ` で水平/垂直の軸ロック）。アニメーション途中の区間では始点・終点を平行移動して傾きを維持します。
  - **拡大縮小**: バウンディング枠の四隅・各辺ハンドルをドラッグ（縦横ロック有効時または `Shift` で等比維持、`Alt+ドラッグ` で中心アンカー基準に拡縮）。
  - **回転**: 上部回転ハンドルをドラッグ（`Shift` で 15° 単位スナップ）。
  - **中心アンカー（`⊕`）**: クロスマーカーをドラッグして回転・拡大縮小の基準点を調整。
  - **パン＆ズーム**: ホイールで拡大縮小、ドラッグパンで表示位置を調整。
- **主音声波形ストリップ**: プレビュー直下にタイムライン全体のミックス音声波形を緑色で描画します。クリックまたはドラッグして即座にシークできます。
- **トランスポートバー**: 先頭 (`Home`) / `1f` 戻る / 再生・一時停止 (`Space`) / 停止 (`Ctrl+Space`) / `1f` 進む / 末尾 (`End`) / `分割 (S)` ボタンを備えます。

## 7. AI チャットと書き出し

### 7.1 AI チャット（`AIチャット` タブ）

- タイムライン構造・タイムライン長設定・選択範囲 `[start, end)`・各クリップのフレーム範囲や中間点一覧が AI コンテキストとして自動連携されます。
- 「30フレームから120フレームに字幕を追加して」「選択範囲に合わせて書き出し長を調整して」「中間点を追加してアニメーションさせて」などの自然言語で編集計画を生成し、`EditCommand` 履歴（`Ctrl+Z` で一括元に戻す可能）として適用できます。

### 7.2 動画・音声の書き出し

メニュー `書き出し` または `Ctrl+E` から書き出しダイアログを開きます。

- **書き出し範囲**:
  - `プロジェクト全体`: タイムライン全長（`0..total_duration_frames`）を書き出します。
  - `選択範囲のみ ([start..end))`: タイムライン上で `[` / `]` や `Shift+ドラッグ` により設定した選択範囲だけを切り出して書き出します（音声開始オフセットも範囲先頭基準へ同期されます）。
- 解像度プリセット・映像/音声コーデック・ビットレート等を設定し、バックグラウンドジョブとしてエンコードを実行できます。
