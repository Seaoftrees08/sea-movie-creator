# ユーザーガイド（基本操作・編集・書き出し）

このガイドでは、`sea-movie-creator` GUI アプリケーションの画面構成と、読み込みからタイムライン編集・アニメーション設定・動画書き出しまでの一連の使い方を説明します。

---

## 1. 画面レイアウト

アプリを起動すると、ダークテーマのシングルウィンドウが表示されます。各ペインの境界はドラッグしてリサイズできます。

1. **上部メニューバー（`ファイル` / `編集` / `再生`）**
   - プロジェクト作成・開閉・メディア読み込み・保存・書き出し・編集・再生制御を行います。
2. **左上: プレビューパネル**
   - 再生ヘッド位置の合成映像を表示し、下部にシークバー・時刻/フレーム表示・トランスポートボタン（`|<` 先頭へ・再生/一時停止・`Stop`・`Split`）を備えています。
   - 元のメディアファイルが移動または削除されたクリップを再生しようとすると、上部に赤い警告バナー **「Media Offline — 対象ファイルが見つかりません（再リンクしてください）」** が表示されます。
3. **左下: タイムラインパネル**
   - 100 レイヤー以上でも高速に描画できる仮想スクロール対応タイムラインです。
   - ツールバーに `+Track`、`Zoom-`、`Zoom+`、`< 60f`、`60f >`、`Snap`、`コピー`、`貼付`、`複製` が並びます。
4. **右側（初期幅 1/5・リサイズ可能）: 4 タブパネル**
   - **`Clip`**: 選択中クリップの位置・大きさ・回転・色補正・不透明度・再生速度・字幕文言・各種アニメーション設定。
   - **`AI Chat`**: AI によるタイムライン編集支援チャット（[AI 連携・MCP・音声プラグインガイド](ai-and-plugins.md) 参照）。
   - **`Layers`**: 各トラック（レイヤー）のクリップ数表示と **`Mute` / `Unmute`** 切替。
   - **`Project`**: プロジェクト名、解像度 / FPS、総フレーム数、素材/レイヤー数、音声クロック種別（`AudioMasterClock` またはデバイス非搭載時の `SystemPlaybackClock` fallback）、最新ステータス表示。

---

## 2. メディア読み込みとタイムライン編集

### 対応メディア形式

`ファイル > メディアを読み込む...`（`Ctrl+I`）からファイルを選択するか、Windows エクスプローラー（OS のファイルマネージャー）からタイムラインへ直接ドラッグ＆ドロップすると、拡張子に応じてクリップとして追加されます（複数ファイルの一括ドロップにも対応）。

- **静止画**: `.png`, `.jpg`, `.jpeg`, `.bmp`, `.webp`, `.gif`
- **音声**: `.wav`, `.flac`, `.ogg`, `.mp3`, `.aac`, `.m4a`
- **動画**: `.mp4`, `.mkv`, `.mov` 等（環境に応じた OS Media Foundation またはオープンソフトウェア `rav1d` / `symphonia` デコーダ経由で読み込み）

### マウスとツールバーによる編集

- **ドラッグ＆ドロップで素材追加**:
  - **空のタイムラインへドロップ**: `Track 1` を自動作成し、ドロップしたフレーム位置へ配置します。
  - **特定トラックの行へドロップ**: そのトラックのドロップ位置（`Snap` ON 時は再生ヘッドや隣接クリップ端へスナップ、既存クリップと重なる場合は空き位置へ自動シフト）に追加します。トラック見出し部やトラック外の余白へドロップした場合は末尾または選択トラックへ追加されます。
  - **複数ファイル一括追加**: ドロップした順に同じトラックへ隙間なく連続配置し、対応外ファイルのみスキップ通知します。追加操作は 1 回の `Ctrl+Z`（Undo）でまとめて取り消せます。
- **シーク**: プレビュー下のシーク操作やタイムラインルーラーの操作、メニュー/ボタンの `|<`（`Home`）で移動します。
- **再生 / 一時停止 / 停止**: `Space` キーまたは `再生 > 再生 / 一時停止`・`Stop` ボタンを使用します。
- **クリップ選択・移動・トリム**:
  - タイムライン上のクリップブロックをクリックして選択します（右パネルの `Clip` タブと連動します）。
  - クリップ本体をドラッグして開始フレームやトラック（レイヤー）位置を移動できます。
  - クリップ左右端をドラッグして開始点・終了点をトリム（非破壊カット）できます。
  - ツールバーの **`Snap`** でフレーム境界や他クリップ端へのスナップを ON/OFF できます。
- **分割・削除・コピー/ペースト/複製**:
  - 再生ヘッド位置でクリップを切るには、プレビュー下の **`Split`**、`Clip` タブの **`現在位置で分割`**、メニュー `編集 > 再生ヘッドでクリップ分割`、または **`S`** キーを押します。
  - コピー（`Ctrl+C`）、再生ヘッド位置への貼り付け（`Ctrl+V`）、複製（`Ctrl+D`）、削除（`Delete`）に対応し、すべての操作は **`Ctrl+Z`（Undo）** / **`Ctrl+Y`（Redo）** で取り消せます。
- **レイヤー追加とミュート**:
  - タイムラインの **`+Track`** ボタンでトラックを追加できます。
  - 右側 **`Layers`** タブからトラック単位で **`Mute` / `Unmute`** を切り替えられます。

### プロジェクトの保存形式

`ファイル > 保存`（`Ctrl+S`）または `名前を付けて保存...`（`Ctrl+Shift+S`）で `*.smc.json`（既定名 `project.smc.json`）として保存できます。メディアパスはプロジェクトファイルからの相対パス優先・絶対パスフォールバックで記録されるため、プロジェクトフォルダごと移動してもリンクが維持されやすくなっています。

## 3. クリップインスペクタ（`Clip` タブ）の使い方

タイムラインでクリップを選択すると、右側 `Clip` タブに以下の設定項目が現れます。

### 対象パラメータスロット

クリップの種類（動画・画像・字幕・音声）に応じて切り替えられます。

- **映像・共通**: `不透明度`, `位置 X`, `位置 Y`, `拡大 X`, `拡大 Y`, `回転°`, `アンカーX`, `アンカーY`, `明度`, `コントラスト`, `彩度`, `色相°`, `ガンマ`
- **字幕クリップ**: `文字サイズ` および字幕テキスト本文の直接編集（**`字幕更新`** ボタン）
- **音声付きクリップ / 音声クリップ**: `音量 (dB)`, `パン`, および **再生速度 (`PlaybackRate`)**（`0.5x` / `1.0x` / `1.5x` / `2.0x` ボタン）

### 合成モード（ブレンドモード）

映像・画像・字幕クリップでは、`通常`・`加算`・`乗算`・`スクリーン`・`オーバーレイ` の 5 種類をボタンで切り替えられます。

### 4 種類のアニメーション（補間）モード

選択中のパラメータスロットごとに、次の 4 モードを切り替えて時間変化を設定できます。

1. **`固定値`**: スライダや数値操作でクリップ全体に単一の値を適用します。
2. **`イージング`**: 開始値・終了値・イージングカーブを指定して滑らかに変化させます。
3. **`キーフレーム`**: タイムライン各フレームにキーフレームを打って値を補間します（一覧の `@フレームf = 値` ボタンでその位置へシーク、`削除` で取り消し、終端外挿モードの切替が可能）。
4. **`数式 f(t)`**: 任意の数式を入力して **`数式適用`** ボタンでアニメーションさせます。利用可能な変数は以下の通りです。
   - `t`: クリップ先頭からの経過秒数
   - `p`: クリップ尺内の進行率（`0.0` 〜 `1.0`）
   - `d`: クリップの全長（秒）
   - `pi`, `e`: 円周率・自然対数の底
   - スケール・オフセット調整ボタンを使って式全体の振幅や基準位置を微調整できます。

## 5. 動画の書き出し（エクスポート）

`ファイル > 動画の書き出し...`（`Ctrl+Shift+E`）を押すと、プラグイン方式の書き出しダイアログが開きます。

### 書き出し手順

1. **エンコーダプラグイン** を選択します（標準同梱は以下の 3 プラグイン）。
2. **プリセット** を選択します。
3. **解像度**（`プロジェクト設定` / `1280x720 (HD)` / `1920x1080 (FHD)`。偶数ピクセルへ自動整合）と **詳細オプション**（ビットレート、エンコード速度、バックエンド、外部 `ffmpeg` パス等）を調整します。
4. 必要に応じて **`出力先変更...`** で保存ファイルを選び、**`書き出し開始`** を押します。処理中は進捗表示と **`書き出しを中断`** ボタンによる安全なキャンセルが可能です。

### 同梱書き出しプラグインとプリセット一覧

| プラグイン ID | プリセット ID / 内容 | コンテナ | 動作要件・ライセンス上の特徴 |
| :--- | :--- | :--- | :--- |
| `sea.export.av1` | `av1_fast`: 標準 AV1 SW (`rav1e` Speed 9 + FLAC)<br>`av1_quality`: 高画質 AV1 SW (`rav1e` Speed 5 / Q75 + FLAC) | `.mkv` | **追加ソフト不要・純粋 Rust 製**。どの環境でも単体で動作し、最も確実に使える既定形式です。 |
| `sea.export.av1` | `av1_hw`: AV1 GPU/HW 支援 (OS Media Foundation + AAC) | `.mp4` | Windows OS Media Foundation AV1 MFT 対応環境向け。 |
| `sea.export.h264` | `h264_mf_hw`: H.264 標準 / HW 支援 (OS Media Foundation + AAC) | `.mp4` | OS 標準機能のみ使用（特許・GPL エンコーダ非同梱）。 |
| `sea.export.h264` | `h264_external_ffmpeg`: 外部 `ffmpeg` CLI 実行 | `.mp4` | ユーザー自身が導入した `ffmpeg`（`PATH` 上または `ffmpeg_path` 指定）を別プロセス起動します。 |
| `sea.export.h265` | `h265_os_hw`: H.265 / HEVC OS HW 支援 | `.mp4` / `.mov` | Windows MF HEVC MFT、または外部 `ffmpeg` 経由のプラットフォーム API を利用。 |
| `sea.export.h265` | `h265_external_ffmpeg`: 外部 `ffmpeg` CLI 実行 (`libx265` 等) | `.mp4` / `.mov` | ユーザー導入済み `ffmpeg` CLI を使用します。 |

> [!IMPORTANT]
> 本アプリおよびプラグインはライセンス安全性のため、**x264 / x265 / libfdk-aac などの GPL・特許エンコーダを一切バンドルしていません**。外部 `ffmpeg` モードを使う場合は、`ffmpeg` をユーザー環境へ別途インストールし `PATH` を通す（または詳細オプションの `外部 ffmpeg コマンド / パス` を設定する）必要があります。`ffmpeg` なしで手軽に書き出したい場合は **`sea.export.av1` の `av1_fast` (.mkv)** をご利用ください。
